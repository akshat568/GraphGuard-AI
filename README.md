# GraphGuard AI

## Temporal Graph-Based Fraud Investigation & Detection System

GraphGuard AI is an explainable fraud-investigation platform that uses
temporal graph learning to detect suspicious financial activity,
investigate transaction networks, identify suspicious structural patterns,
and explain model predictions.

## Core Research Question

Does graph information provide additional predictive value over
traditional feature-based machine learning for illicit transaction
detection under realistic temporal evaluation?
